Busca Vagas de TI

Um site dedicado à busca de oportunidades de emprego na área de Tecnologia da Informação (TI), direcionando diretamente para o site principal das vagas disponíveis.

Tecnologias Utilizadas

HTML, CSS e JavaScript: Construção da interface e interatividade

Python: Processamento de busca e direcionamento

Funcionalidades

Busca de vagas relacionadas à área de TI por palavras-chave

Exibição de resultados relevantes

Redirecionamento direto para o site original da vaga
